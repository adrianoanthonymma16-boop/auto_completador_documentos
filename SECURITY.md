# Security Policy

## Reporting a Vulnerability

To report a security vulnerability, send an email to:

**adrianoanthonymma16@gmail.com**

Please include:
- Detailed description of the vulnerability
- Steps to reproduce
- Affected versions

Do not open public issues for security vulnerabilities.

## Supported Versions

| Version | Supported          |
|---------|-------------------|
| 3.6.x   | Yes               |
| 3.5.x   | Yes               |
| < 3.5   | No                |

## Security Design

- 100% offline — no network requests, no cloud processing
- All data processed locally on the user's machine
- No telemetry or data collection
- Documents stored only in user-defined paths
